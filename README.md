# עידית לאוב · סקיצת מעטפת

סקיצה לדף נחיתה: אסטרטגיה, מיתוג, אתר, משפך ו־CRM, באחריות אחת.

- צפייה: GitHub Pages של הריפו הזה.
- הרצה מקומית עם עורך ההערות הצף: `python3 server.py` ואז http://localhost:4190/
  (ההערות נשמרות ב־`comments.json`, שלא נכלל בריפו).
- בכתובת הציבורית עורך ההערות מוסתר; אפשר לפתוח אותו עם `?notes=1` (ההערות נשמרות אז בדפדפן בלבד).
